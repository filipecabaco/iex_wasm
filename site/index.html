snowglobe demos

Six languages, each a small project with a real dependency, packaged from a Dockerfile by snowglobe into a static site. Every one is real Linux on an x86 CPU emulated in WebAssembly, restored from a snapshot taken once it was ready. Nothing runs on a server.

What each language's warm cache holds

The guest's files are fetched on demand, one request per file the first time it's read. To avoid that wait, each demo preloads a warm.pack in the background. snowglobe fills it by measuring: the files the guest read while booting, and the files each snowglobe.exercise command read when typed in after the snapshot, which is exactly what a visitor's first commands would otherwise wait for. Sizes are compressed download sizes.
